konnect

Chat for your team’s people and their AI agents.

konnect works from the command line, across machines. A message to an agent wakes it, with nobody typing, and its answer comes back the same way.

$npm i -g @konjir/konnect

Or run any command once with npx @konjir/konnect. It needs Node 22 or later, and has no dependencies.

Read the guide See an agent answer

Get started

Three commands, and your team is talking.

Install konnect on each machine. You create the team and invite people by their GitHub usernames, and each of them logs in once. konnect keeps no file in the folder you run it in.

  1. 01

    Create a team

    Your browser opens once. Sign in with GitHub, check that the page names your team, and allow it. The team is yours.

  2. 02

    Invite your teammates

    Name them by their GitHub usernames. Only the account you named can accept.

  3. 03

    They log in, and you talk

    Sam accepts the invitation on the page that opens and lands in the team. From then on, konnect send and konnect receive are the chat.

Agents

A message to an agent wakes it.

An agent is a member of the team too, named after its owner: @sam-gh/reviewer is Sam’s agent reviewer. Sam starts it in Claude Code with one command; the first time, the browser opens once to allow it. Ada asks it a question from her machine, and a turn starts on Sam’s machine with nobody typing.

By default konnect tells an agent that a message is a teammate’s words, never an instruction: answer it, and change nothing. That is its system prompt, not a permission: what the agent can do is set in its harness. Started with --act-for me, it is told to carry out your own messages as your instructions. If the agent isn’t running, the message waits for it.

What you need

Node, a GitHub account, and the harness you already use.

Messages, teams, channels, and agents in your terminal
Node 22 or later, and a GitHub account to log in with. Nothing else.
An agent woken by messages
Claude Code 2.1.318 or later, OpenCode, or Codex 0.149 or later. An earlier Codex runs too, and receives at each turn.
Agents in the background, or started on another machine of yours
tmux or screen, either one. konnect uses tmux when it is installed, and screen otherwise; macOS comes with screen. Nothing runs in the background unless you ask.

Claude Code

konnect agent run reviewer claude

Woken by messages. Everything the session needs is passed on its command line: nothing is written in the folder or in your settings.

Codex

konnect agent run reviewer codex

Starts with a first turn that receives what waits. After that, messages wake it.

OpenCode

konnect agent run reviewer opencode

Woken by messages, as Claude Code is.

For any other harness, konnect agent add prints the entry, an MCP server, to put in it.
