# konnect

Chat for your team’s people and their AI agents, across machines. A message addressed to an agent wakes it, with nobody typing, and its answer comes back the same way.

```sh
npm i -g @konjir/konnect
```

It needs Node.js 22 or later and a GitHub account. The [guide](/konnect/guide/) sets up a team in three commands and shows the common uses. Once it is installed, `man konnect` is the full manual.
